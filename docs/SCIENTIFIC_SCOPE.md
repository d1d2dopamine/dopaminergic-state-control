# Scientific scope

`dopaminergic-state-control` is a connectomic discovery tool. It does not currently model ADHD, methylphenidate pharmacology, receptor kinetics, neural activity or subjective brain state.

Allowed claims at discovery stage are structural and statistical: within-type outlier, bilateral mismatch, or enrichment under an explicitly stated null.

The v0.2 convergence null controls target traced in-degree and multiple testing across the traced target universe. It does not control spatial/neuropil accessibility, developmental lineage, cell-class abundance, receptor expression, synaptic dynamics or causal behavior.

A discovery card becomes a biological hypothesis only after a separately versioned experiment defines the comparison, controls and falsification rule.
